# Oguzkaan AI - Yapay Zeka Asistanı

> 🤖 TEKNOFEST 2024 Yarı Final Projesi | Modern yapay zeka asistanı ve görsel oluşturma aracı | AI sohbet ve görsel üretim teknolojileri

Bu proje, TEKNOFEST 2024 yarışması için geliştirilmiş modern bir yapay zeka asistanı ve görsel oluşturma aracıdır. Kullanıcı dostu arayüzü ve gelişmiş özellikleriyle, yapay zeka teknolojilerini herkes için erişilebilir kılmayı amaçlamaktadır.

## 🚀 Özellikler

- **Yapay Zeka Sohbet**
  - Anlık mesajlaşma arayüzü
  - Akıllı cevap sistemi
  - Enter tuşu desteği
  - Shift + Enter ile çok satırlı mesaj gönderme

- **Görsel Oluşturma**
  - Metin tabanlı görsel üretimi
  - Yüksek kaliteli AI görsel çıktısı
  - Kullanıcı dostu arayüz
  - Gerçek zamanlı önizleme

## 💻 Teknolojiler

- HTML5
- CSS3
- JavaScript (ES6+)
- PHP
- Oğuzkaan API
- Modern UI/UX Prensipleri

## 🛠️ Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/ibidi/oguzkaan-ai.git
```

2. Proje dizinine gidin:
```bash
cd oguzkaan-ai
```

3. Bir PHP sunucusu başlatın:
```bash
php -S localhost:8000
```

4. Tarayıcınızda açın:
```
http://localhost:8000
```
